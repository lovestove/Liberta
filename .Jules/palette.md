## 2024-05-18 - Jetpack Compose Switch Accessibility
**Learning:** Adding a `contentDescription` to a decorative child icon next to descriptive text causes screen readers to redundantly announce the description twice. Additionally, when nesting a `Switch` within a `Row`, the parent `Row` should handle the toggling via `Modifier.toggleable(role = Role.Switch)` while the inner `Switch` should have its `onCheckedChange` disabled (`null`). This expands the touch target, avoids double-firing events, and correctly merges semantics for a seamless accessibility experience.
**Action:** When a descriptive text label fully explains an adjacent icon, set the icon’s `contentDescription` to `null`. For switch rows, apply `Modifier.toggleable` to the parent row and disable the inner switch’s state change handler.
