## 2024-05-24 - Accessibility insights with Compose Switches and Info Icons
**Learning:** In Jetpack Compose, applying `clickable` or `toggleable` directly to a `Switch` within a larger clickable row can cause the screen reader to announce the action twice or misinterpret the semantics. The parent container (`Row`) should handle the `toggleable` modifier with `Role.Switch`, and the inner `Switch` should have its `onCheckedChange` set to `null` to merge the interaction state correctly. Additionally, adding `contentDescription` to purely decorative icons (like info icons) next to descriptive text causes redundant readouts.
**Action:** When creating toggleable list items, always apply `Modifier.toggleable` (with `Role.Switch`) to the parent container and disable interaction on the inner `Switch`. Leave `contentDescription` as `null` for icons when the surrounding text provides the same context.
