## 2026-06-29 - Improve Switch Accessibility with Row Toggleable
**Learning:** In Jetpack Compose, when building list items that contain a Switch, do not apply `Modifier.clickable` to the parent `Row`. This creates a smaller tap target or requires exact tapping on the switch. Instead, apply `Modifier.toggleable(value = ..., role = Role.Switch, onValueChange = ...)` to the parent `Row`, and set the internal `Switch`'s `onCheckedChange` to `null`. This merges the screen reader semantics correctly and makes the entire row an accessible toggle button.
**Action:** Always use `Modifier.toggleable` with `Role.Switch` on parent containers of switch components to ensure proper tap targets and unified accessibility announcements. Additionally, ensure decorative sibling icons have `contentDescription = null` to prevent screen readers from redundantly announcing text that is already visible and read elsewhere in the UI.
