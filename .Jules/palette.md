## 2024-05-24 - ToggleLine Touch Target and Screen Reader Polish
**Learning:** By default, standard Jetpack Compose Switch elements have a small touch target that can be difficult to tap on mobile devices. Wrapping them in a Row and adding a click listener works but applying `Modifier.toggleable` to the Row with `role = Role.Switch` is much better because it merges the semantics for accessibility correctly. Furthermore, when the description of a setting is visibly present under the label, repeating that description as `contentDescription` on an adjacent Info icon causes redundant, annoying screen reader announcements.
**Action:** When building custom toggle rows, use `Modifier.toggleable` on the container, pass `null` to the child Switch `onCheckedChange` to avoid double-firing events, and set purely decorative or visually redundant icons’ `contentDescription` to `null` to avoid double-speaking.
